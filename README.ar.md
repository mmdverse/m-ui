## نظرة عامة

**M-UI** لوحة تُستضاف ذاتياً لإدارة الخوادم وإعدادات البروكسي والأنفاق. تنشئ
وصولاً حقيقياً على أجهزة حقيقية عبر SSH، وتُبقي روابط المشاركة ثابتة، وتُنمذج —
وهو ما تتجاهله أغلب اللوحات — **نظام الحجب بين العميل والخادم**، بحيث يمكن تقييم
الإعداد قبل وصوله إلى المستخدم.

**مجاني ومفتوح: رخصة MIT — استخدام شخصي وتجاري واستضافة ذاتية، بلا قيود.**

| | ما هو | أين |
|---|---|---|
| **اللوحة** | الخوادم، المراقبة، الإعدادات، الأنفاق، المستخدمون والأدوار، نشر SOCKS5، WireGuard، واجهة بخمس لغات | `src/pages` · `src/lib` |
| **محرّك الرقابة** | ١١ بلداً × ١٨ طبقة حجب × ١٥ خطة عبور، نموذج تقييم، وتوليد إعداد لكل بلد | `src/lib/censorship` |
| **المختبر** | محاكي DPI بلغة Python ومختبر شامل على Xray حقيقي، والنموذج مسؤول أمامهما | `testenv/censor` · `testenv/world-matrix.py` |

المحرّك والمختبر ليسا ديكوراً: يفشل `npm test` إذا تباعد النموذج والمحاكي، أو
إذا وُصفت طبقة بأنها «محاكاة» دون قياس خلفها، أو إذا رفض Xray نفسه إعداداً
مولّداً.

## المزايا

| المجال | ما يفعله |
|---|---|
| **الخوادم** | إضافة بكلمة مرور أو مفتاح SSH. يُختبر الاتصال قبل الحفظ؛ والأسرار تُشفَّر ولا تُعاد أبداً عبر الـ API. |
| **المراقبة** | CPU وRAM وload وuptime والحركة من `/proc` على الخادم نفسه، بقياس دوري ومخطط لسبعة أيام. الخادم المتوقف يُعلَّم «قديماً» بدل عرض أرقام وهمية. |
| **الإعدادات** | روابط VMess وVLESS وTrojan وShadowsocks مع TLS وWebSocket وgRPC وHTTP وKCP وQUIC وCDN؛ وREALITY (`pbk`/`fp`/`sid`)؛ وXHTTP بنمط `stream-up`. |
| **هوية ثابتة** | يُولَّد UUID وكلمة المرور مرة واحدة، فلا يتغيّر الرابط على المستخدم. |
| **نشر SOCKS5** | تثبيت وتشغيل microsocks على الخادم الهدف ببيانات دخول لكل إعداد على حدة: `apt` و`dnf` و`yum` و`apk`. |
| **WireGuard** | زوج مفاتيح X25519 وملف `.conf` جاهز للاستيراد. |
| **الأنفاق** | أنفاق SSH العكسية تُشغَّل وتُوقَف فعلياً عبر OpenSSH. أنفاق Direct وFRP وWireGuard تُسجَّل حالياً دون تنفيذ. |
| **مستشار الاتصال** | يقيّم الإعداد وفق ملف الشبكة التي سيعمل فيها: نطاقات محجوبة، منافذ مغلقة، بصمات uTLS، تعامل UDP، قوائم البروتوكولات المسموحة. |
| **أطلس الحجب** | صفحة لكل بلد: طبقات الحجب بدرجة شدتها وموثوقيتها، الخطط المرتبة مع السبب، إعداد مولّد للخطة الفائزة، خط الأنفاق، والمصادر خلف كل ادعاء. |
| **خط الأنفاق** | سلاسل مدخل → مُرحّل → مخرج، مع إعداد Xray حقيقي لكل عقدة يُتحقق منه بتشغيل `xray run -test` في الاختبارات. |
| **التحكم بالوصول** | جلسات JWT، تجزئة bcrypt، تحديد محاولات الدخول بزمن استجابة موحّد، وأدوار مفعّلة على كل مسارات الكتابة. |
| **النشر** | `docker compose` من المصدر أو `npm ci && npm run build`. في وضع production لا تعمل اللوحة دون `JWT_SECRET`. |

## كيف يعمل نموذج الرقابة

لكل زوج (بلد، خطة) يجيب المحرّك: *إذا اتصل العميل بهذه الطريقة من تلك الشبكة،
فأي طبقات حجب تُسقطه، وما الذي يعوّض ذلك؟*

**الطبقات** ١٨ آلية: تسميم DNS، إعادة تعيين SNI، إسقاط ECH، إعادة تجميع TCP،
بصمة QUIC v1، قواعد حركة مُشفَّرة كلياً، قوائم JA4 المسموحة، قوائم البروتوكولات
المسموحة، حجب IP/ASN، الفحص النشط، تصنيف التدفّق، واستكشاف TLS-in-TLS.

**الخطط** ١٥ تركيبة من البروتوكول والنقل والحماية والتمويه: من
`VLESS + REALITY + Vision + finalmask` إلى `WireGuard` المجرّد.

**البلدان** ١١ ملفاً بدرجة الشدة ووسم الموثوقية: `measured` أو `reported` أو
`heuristic`.

```text
score = 100 − Σ penalty
penalty = 5 × severity   للطبقة المكشوفة        (1–5)
        + 3 × severity   للطبقة المغطاة جزئياً
        + 40             إذا كان منفذ الخطة محجوباً في البلد

85+  صامد      65–84  صالح للاستخدام      45–64  هشّ      أقل من ذلك: تجنّبه
```

## الهندسة العملية حسب البلد

### 🇷🇺 روسيا — TSPU / RKN

أصعب ملف في النموذج. TSPU في المسار وبحالة: يعيد تجميع **تدفّق TCP و**سجلات
TLS؛ يُسقط حزم QUIC v1 Initial التي تتجاوز ١٠٠٠ بايت كلياً؛ يُسقط مصافحات ECH؛
يحجب ASN السحابية الأجنبية على مستوى SYN؛ ووفق تقارير منتصف ٢٠٢٥ يعمل في بعض
المناطق بـ**قائمة SNI مسموحة**.

| الطبقة | الشدة | الموثوقية | ما تفحصه |
|---|:--:|:--:|---|
| `sni_block` | 5 | measured | SNI وفق قائمة، مع تخنيق بحسب SNI |
| `proto_fingerprint` | 5 | measured | مصافحات ثابتة: initiation بحجم ١٤٨ بايت في WireGuard، أكواد OpenVPN |
| `reassembly` | 4 | measured | إعادة تجميع سجلات TCP **و** TLS |
| `quic_v1_fingerprint` | 4 | measured | QUIC v1 Initial بحمولة تتجاوز ~١٠٠٠ بايت |
| `ip_block` | 4 | measured | ASN سحابية أجنبية (Hetzner، OVH، DigitalOcean) على مستوى SYN |
| `sni_whitelist` | 4 | reported | وضع قائمة SNI المسموحة (إقليمي) |
| `ech_drop` | 3 | measured | ClientHello يحمل ECH — منذ نوفمبر ٢٠٢٤ |
| `udp_filter` | 3 | measured | UDP بخلاف DNS |
| `ml_flow` | 3 | reported | تصنيف إحصائي للتدفّق |

**ما ينجح**

1. **اقطع مرّتين.** أهم نتيجة في النموذج: تقطيع مقاطع TCP وحده غير كافٍ، وتقطيع
   سجلات TLS وحده غير كافٍ؛ والاثنان معاً يكسران إعادة التجميع لأن أيّاً منهما
   لا يُعاد بناؤه مستقلاً. تمنح `reality-vision-frag` **٦٧ مقابل ٣٢** لنفس
   البروتوكول دون تجزئة.
2. **استخدم `finalmask` لا `streamSettings.fragment`.** قياس على Xray 26.3.27:
   المفتاح القديم ينتج سجلاً واحداً بحجم ١٨١٨ بايت، و`finalmask` ينتج **خمسة
   سجلات** `[118, 155, 192, 183, 1106]` بشكل حتمي.
3. **اعتبر QUIC v1 محجوباً.** وفق قاعدة الملف يُسقط التدفّق كاملاً لا حزمة واحدة.
   لا تنجو Hysteria2 هنا إلا بنسخة Initial غير معروفة، وهي جزئية.
4. **أبقِ ECH مغلقاً.** مصافحة ECH نحو SNI الخاص بـCloudflare تُسقَط.
5. **لا تختَر ASN سحابية محروقة.** إن كان عنوان الدخول في ASN محجوب، فلا يهم
   ما سبق.

**الحكم:** `reality-vision-frag` — **٦٧/١٠٠**، الخطة الوحيدة في النطاق الأعلى.

### 🇨🇳 الصين — GFW

مصنّف لا قائمة. الجزء الموثوق تسميم DNS وحجب SNI؛ والجزء المثير هو **كشف
الحركة المُشفَّرة كلياً** بخمس قواعد استثناء وتنفيذ احتمالي، وفك تشفير QUIC
Initial على نطاق واسع.

**ما ينجح**

1. **مرّ من قائمة الاستثناء، لا تتجاوزها.** القواعد بنيوية: نسبة المحارف
   المطبوعة، أطول سلسلة مطبوعة، أوائل البايتات المطبوعة، نطاق إنتروبيا
   popcount، وبصمة بروتوكول معروفة. يفشل Shadowsocks-2022 المجرّد في الخمسة
   بحكم تكوينه: كل بايت عشوائي من الصفر. تغليفه في TLS + WebSocket يرفع النتيجة
   من ٠ إلى ٤٩–٨٨.
2. **الحجب احتمالي، والمختبر يثبته.** في تشغيل حقيقي أُعيد تعيين SS-2022 في
   **٤–٥ من ٨** اتصالات، وVMess-over-TCP في **٣–٥ من ٨**، بحسب الملح العشوائي
   في الحزمة الأولى. لذلك تُوصف الحالة `mixed` لا `block`.
3. **افصل التدفّقات.** لهذا وُجد XHTTP: مع `mode: stream-up` يعيش الرفع
   والتنزيل في تدفّقين مختلفين، فتفقد القاعدة التي تحتاج اتجاهي اتصال واحد
   قبضتها. `reality-xhttp` أفضل خطة هنا: **٨٨/١٠٠**.
4. **QUIC آمن فقط بلا نسخة.** الـ Initial القابل لفك التشفير يُفك ويُرشَّح؛
   أما غير المعروف النسخة فلا يُفك أصلاً.

**الحكم:** `reality-xhttp` — **٨٨/١٠٠**، ثم `reality-vision-frag` و
`reality-vision` بـ٧٦.

### 🇮🇷 إيران — عائلة NGFW والترشيح الوطني

تسميم DNS، إعادة تعيين SNI، والأهم: **قائمة بروتوكولات مسموحة** — لا يخرج من
البلد سوى DNS وHTTP(S). أي نفق لا يتّخذ شكل TLS على منفذ مسموح يُسقَط بصرف النظر
عن رقم المنفذ.

**ما ينجح**

1. **كن TLS على ٤٤٣.** REALITY هو الطريق الأقصر: المصافحة مصافحة TLS حقيقية مع
   موقع حقيقي، والشهادة مستعارة من وجهة غير محجوبة.
2. **لا ترسل نمط الأطوال المتداخل.** `flow: xtls-rprx-vision` يزيل بصمة أحجام
   السجلات الداخلية، ولهذا يتدهور Trojan وVMess-over-TLS البسيطان هنا.
3. **اقطع على مستوى السجل والمقطع.** `finalmask` يقسّم ClientHello إلى سجلات
   TLS متعددة بفاصل زمني، فلا يظهر SNI كاملاً في مقطع واحد. أما المفتاح القديم
   `streamSettings.fragment` فيتجاهله Xray 25+ بصمت.
4. **لا تعتمد على UDP.** أي خطة بـQUIC أو WireGuard هنا تبلغ ٣٣ أو أقل.

**الحكم:** عائلة REALITY — **٩١/١٠٠**؛ وكل ما لا يشبه TLS بين ٠ و٤٥.

### 🇹🇲 تركمانستان — قائمة مسموحة كاملة

ليست مرشّحاً بل قائمة دخول: لا يُسمح إلا لمجموعة صغيرة من النطاقات الوطنية
والخدمات المعتمدة، والجواب الافتراضي «لا».
**ما ينجح:** الاحتماء خلف CDN (`ws-tls-cdn` → **٨٠/١٠٠**، أفضل نتيجة في البلد)،
وSNI من المجموعة المسموحة حصراً، واختيار ASN الخاص بـCDN لا بـVPS، وتجنّب أي
خطة تعتمد UDP.

### 🇦🇪 الإمارات — قائمة بصمات JA4 مسموحة

البلد الوحيد الذي تحكم فيه **قائمة بصمات TLS مسموحة**: يتوقّع DPI رؤية ClientHello
متصفح حقيقي. **ما ينجح:** إرسال بصمة متصفح بايتاً ببايت؛ و**JA4 لا JA3** — فقد
أظهر قياسنا أن ١٥ اتصالاً متتالياً بملف `chrome` أنتجت **١٥ بصمة JA3 مختلفة**
لأن Chrome يعيد ترتيب الإضافات، مقابل **JA4 واحدة ثابتة**
`t13d1516h2_8daaf6152771_8ee26baaef31`؛ وتجنّب البصمة العشوائية التي تتغيّر كل
اتصال فلا تُدرج في أي قائمة (المختبر يتحقق من هذه الحالة بالضبط:
`ae-tls-randomized` → حجب بسبب `ja4_fingerprint`).
**الحكم:** REALITY والخطط ذات البصمة المتصفحية — **٩٤/١٠٠**.

| ١ | **استقرار JA3 مقابل JA4** (uTLS Chrome على Xray 26.3.27) | ١٥ اتصالاً → **١٥ JA3 مختلفة**، **JA4 واحدة**. مفتاح القرار JA4. | `testenv/censor/fpmeasure.py --cert <cert> --write-ts` |
| ٢ | **`fragment` القديم مقابل `finalmask`** | المفتاح القديم بلا أثر: سجل واحد بحجم ١٨١٨ بايت. و`finalmask` → **٥ سجلات** `[118, 155, 192, 183, 1106]`. | `testenv/frag-probe.py` |
| ٣ | **فصل المقاطع مقابل فصل السجلات** | فصل السجلات حتمي وقابل للادعاء؛ أما فصل مقاطع TCP فلا، لأن النواة تدمج الكتابات المتتالية. الاختبارات تدّعي `record_split` وتُبلّغ فقط عن `tcp_split`. | `testenv/frag-probe.py`، `testenv/world-matrix.py` |
| ٤ | **الكلفة لكل عقدة** | عقدة واحدة ٩١٫٤٦٣ms، وثلاث عقد ٩١٫٩٠٦ms → **٠٫٢٢٢ms لكل عقدة**. | `testenv/transit-lab.py` |
| ٥ | **مفتاح REALITY البديل يُرفَض** | يخرج Xray بالرمز **rc=23**، فلا يمكن تشغيل إعداد مولّد ناقص بالخطأ. | `tests/transit.test.ts` |

النموذج هو مصدر الحقيقة: يُولَّد `rules.json` من `countries.ts` ويُقارن بايتاً
ببايت، فلا يمكن لمحاكي Python أن يتباعد عن نموذج TypeScript.

## مختبر DPI

```text
  عميل xray ──► وسيط الحجب ──► خادم xray ──► منصة القياس ──► الوجهة
  (إعداد حقيقي)   (قواعد البلد)  (reality/tls/    dest:9447      http/https
                                 ss/vmess)
                    │
                    └──► قرار لكل تدفّق + دليل
```

خمس عشرة حالة عبر `python3 testenv/world-matrix.py`: `ru-reality-frag`
(allow مع `record_split`)، `ru-reality-plain` (شاهد)، `ru-reality-blocked-sni`
(`sni_block`)، `tm-whitelisted-sni` / `tm-other-sni` (`sni_whitelist`)،
`ir-reality` / `ir-ss2022` (`proto_whitelist`)، `ae-tls-chrome` /
`ae-tls-randomized` (`ja4_fingerprint`)، `cn-tls-not-simulated`،
`cn-reality-vision`، `cn-reality-frag`، `cn-ss2022` و`cn-vmess-tcp`
(`fep_detect`، `mixed` ٤–٥ و٣–٥ من ٨)، و`open-ss2022-control`.

نفس المنصة والقواعد: يشغّل `python3 testenv/censor/selftest.py` عدد **٦٦**
فحصاً على مستوى المحاكي.

## خط الأنفاق متعدد العقد

| العقدة | الدور | الخطة | لماذا |
|---|---|---|---|
| `tr:443` | مدخل | REALITY + Vision + finalmask ببصمة Chrome | الساق الوحيدة التي يراها البلد الحاجب؛ كل الطبقات عالية الشدة تُعوَّض هنا |
| `de:8443` | مُرحّل | REALITY + Vision | عنوان المدخل قابل للاحتراق: عند موته يبدّل المستخدم عنوان IP لا الإعداد |
| `nl:2053` | مخرج | REALITY + Vision | أقرب إلى خدمات الوجهة؛ هذا هو العنوان الذي يراه العالم |

`hopConfigs()` ينتج إعداداً لكل عقدة وإعداد العميل، و`tests/transit.test.ts`
يمرّر كل إعداد مولّد عبر `xray run -test` بمفاتيح X25519 جديدة. الكلفة المقيسة:
**+٠٫٢٢٢ms لكل عقدة** (على loopback؛ التأخير الجغرافي غير منمذج).

## البدء السريع

```bash
git clone https://github.com/mmdverse/m-ui
cd m-ui
cp .env.example .env        # املأ JWT_SECRET و ADMIN_PASSWORD
npm ci
npm run build && npm start
```

تعمل اللوحة على `http://localhost:3000`، ويُنشأ أول مدير من متغيّرات البيئة عند
أول تشغيل.

```bash
JWT_SECRET=$(openssl rand -hex 32) \
ADMIN_PASSWORD='كلمة-مرور-قوية' \
MONGO_PASS='كلمة-مرور-القاعدة' \
  docker compose up -d
```

<details>
<summary><b>متغيّرات البيئة</b></summary>

| المتغيّر | مطلوب | الغرض |
|---|:--:|---|
| `JWT_SECRET` | ✔ (production) | توقيع الجلسات؛ دونها لا تعمل اللوحة في production |
| `MONGODB_URI` | ✔ | سلسلة اتصال MongoDB |
| `M_UI_ENCRYPTION_KEY` | مُستحسن | تشفير الأسرار المخزَّنة مستقلاً عن `JWT_SECRET` |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | أول تشغيل | إنشاء أول مدير (٨ محارف على الأقل) |
| `PORT` | — | منفذ اللوحة، ٣٠٠٠ افتراضياً |

# چندزبانه بودن پنل

پنل در پنج زبان کار می‌کند: **فارسی (پیش‌فرض)**، انگلیسی، روسی، عربی و چینی.
زبان از `localStorage` (کلید `mui_locale`) خوانده می‌شود؛ اگر آنجا چیزی نبود،
از زبان مرورگر کاربر (`navigator.languages`) نزدیک‌ترین زبان پشتیبانی‌شده انتخاب
می‌شود و در نهایت فارسی. جهت صفحه هم خودکار عوض می‌شود: `fa`/`ar` راست‌به‌چپ،
بقیه چپ‌به‌راست.

## ساختار

| فایل | نقش |
|---|---|
| `src/i18n/fa.ts` | **منبع حقیقت کلیدها**. هر کلید تازه اول اینجا اضافه می‌شود (`as const`). |
| `src/i18n/{en,ru,ar,zh}.ts` | همان کلیدها با تایپ `Record<MsgKey, string>` — اگر کلیدی جا بماند، `tsc` خطا می‌دهد. |
| `src/i18n/core.ts` | منطق خالص: تشخیص زبان، `translate()`، درج مقادیر `{var}`، قالب‌بندی تاریخ. بدون React (تست‌ها مستقیم از این استفاده می‌کنند). |
| `src/i18n/index.tsx` | لایهٔ React: `I18nProvider`، `useI18n()`، `useT()`. |
| `src/components/LanguageSwitcher.tsx` | انتخابگر زبان در نوار بالا (و در صفحهٔ ورود). |

درج مقدار در متن با `{name}` انجام می‌شود:

```ts
t('srv.connected', { cpu: 12, ram: 40, load: '0.31' })
```

## خطاهای API هم ترجمه می‌شوند

پیام خطای بک‌اند فارسی است (برای مصرف مستقیم API و لاگ‌ها)، ولی کنارش یک
**کد پایدار** و در صورت نیاز `vars` برمی‌گردد:

```json
{ "error": "پورت باید عددی بین ۱ تا ۶۵۵۳۵ باشد", "code": "api.portRange" }
{ "error": "تلاش‌های ناموفق زیاد بود؛ ...", "code": "api.rateLimited", "vars": { "sec": 600 } }
```

`src/lib/api.ts` این کد را روی `ApiError` نگه می‌دارد و `apiErrorText(err, t)`
آن را در زبان فعال ترجمه می‌کند؛ اگر کد ناشناس بود، همان `error` خام نمایش داده
می‌شود (پس هیچ‌وقت پیام خالی یا کلید لخت دیده نمی‌شود). کدها در `validate.ts`
با `apiError(...)` ساخته می‌شوند.

## رویدادهای سیستم (صفحهٔ «رویدادها»)

هر ردیف تازهٔ فعالیت، علاوه بر متن فارسی، `code` و `vars` هم ذخیره می‌کند
(`act.*`)؛ صفحهٔ لاگ کد را ترجمه می‌کند و ردیف‌های قدیمی‌تر که کد ندارند با متن
ذخیره‌شده‌شان نمایش داده می‌شوند.

## تست‌ها

`tests/i18n.test.ts` این‌ها را تضمین می‌کند (بخشی از ۶۷ تست پروژه):

- هر چهار دیکشنری **دقیقاً** همان کلیدهای فارسی را دارند، بدون مقدار خالی.
- جای‌نگهدارهای `{var}` بین زبان‌ها یکسان است.
- هیچ متن ترجمه‌نشده‌ای از فارسی کپی نشده (تشخیص با حروف مخصوص فارسی: پ چ ژ گ ک ی).
- هر `t('key')` ثابت در کد به کلید موجود اشاره می‌کند.
- هر `api.*` و `act.*` که کد تولید می‌کند در هر پنج دیکشنری وجود دارد.
- خروجی پنج زبان برای یک نمونهٔ متن، متفاوت و کامل است.

## افزودن زبان تازه

۱. `src/i18n/xx.ts` را از `fa.ts` بسازید و `Record<MsgKey, string>` را پر کنید.
۲. در `core.ts`: به `LOCALES`، `LOCALE_META` (label/tag/dir/short) و `TABLES` اضافه‌اش کنید.
۳. اگر زبان راست‌به‌چپ است، فقط `dir: 'rtl'` کافی است؛ CSS با ویژگی‌های منطقی
   (`inset-inline-*`، `border-inline-start`) نوشته شده است.
۴. فونت اختصاصی (اگر لازم بود) را در بخش «چندزبانه» انتهای `src/styles/globals.css` اضافه کنید.
۵. `npx vitest run` و `npm run build`.

## چه چیزی عمداً ترجمه نشده

- کامنت‌های کد و مستندات: فارسی می‌مانند.
- متن خام `error`/`event` ذخیره‌شده در دیتابیس و ردیف‌های قدیمی لاگ: فارسی می‌مانند
  (فقط نقش fallback دارند و در UI با کد ترجمه‌شده جایگزین می‌شوند).
- نام و موقعیت سرورها: دادهٔ کاربر است، دست‌نخورده نمایش داده می‌شود
  (موقعیت نامشخص حالا خالی ذخیره می‌شود و UI آن را ترجمه می‌کند).
